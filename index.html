🔒 Политика конфиденциальности LUSEAM

1. Сбор данных

Мы собираем минимально необходимые данные для работы платформы:

  • Никнейм и email для регистрации
  • Cookies для авторизации и сохранения настроек
  • Обобщенные IP-адреса (первые 3 октета) для безопасности
  • Точные IP-адреса хранятся только для административных целей и автоматически удаляются через 3 месяца

2. Просмотр IP администрацией

В целях обеспечения безопасности платформы, администрация имеет право просматривать IP-адреса пользователей:

  • Только для предотвращения мошенничества и нарушений
  • Только администраторы и основатель имеют доступ
  • Данные об IP-адресах хранятся в зашифрованном виде
  • Все IP-адреса автоматически удаляются через 3 месяца

3. Автоматическое удаление данных

В соответствии с политикой конфиденциальности:

  • Данные об IP-адресах удаляются автоматически через 3 месяца
  • Аналитические данные удаляются через 6 месяцев
  • Неактивные аккаунты удаляются через 12 месяцев
⚠️ Внимание:

Администрация имеет доступ к IP-адресам пользователей только для обеспечения безопасности платформы. Эти данные удаляются автоматически через 3 месяца.

4. Согласие пользователя

Используя платформу LUSEAM, вы подтверждаете, что:

  • Вам больше 9 лет (или вы получили разрешение от родителей)
  • Соглашаетесь на использование cookies для работы платформы
  • Принимаете условия автоматического удаления данных
  • Понимаете, что администрация имеет доступ к IP-адресам для безопасности

📜 Пользовательское соглашение LUSEAM

1. Общие условия

Настоящее Соглашение регулирует отношения между администрацией платформы LUSEAM и пользователем.

2. Возрастные ограничения

Платформой могут пользоваться лица от 9 лет. Для пользователей младше 13 лет:

  • Регистрация разрешена без дополнительных согласий
  • Родители могут запросить удаление аккаунта ребенка
  • Ограничен доступ к некоторым функциям платформы

3. Сбор данных и просмотр IP

Для обеспечения безопасности и работы платформы мы собираем:

  • Cookies для авторизации (обязательно)
  • Точные IP-адреса для защиты от мошенничества (административный доступ)
  • Данные об использовании для аналитики (анонимно)

✅ Законность: Сбор и просмотр IP-адресов администрацией для безопасности платформы является законным и соответствует политике RuStore. Данные удаляются через 3 месяца.

4. Права администрации

Администрация платформы имеет право:

  • Просматривать IP-адреса пользователей для предотвращения мошенничества
  • Блокировать аккаунты за нарушение правил
  • Удалять вредоносный контент
  • Проверять игры на модерации

Используя платформу LUSEAM, вы автоматически соглашаетесь на использование cookies для работы платформы и предоставляете право администрации просматривать ваши IP-адреса для обеспечения безопасности.
